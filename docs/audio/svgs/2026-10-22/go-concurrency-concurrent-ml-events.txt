欢迎收听每日技术学习语音讲解。本期主题，CML：把通信操作变成可组合的事件值。标签包括Concurrent ML、Go select、CSP、goroutine 泄漏。本次讲解预计时长 约 8 到 9 分钟，共 11 个部分。好，我们开始。

一句话概括。本文解决的核心问题是：Go 的 channel/select 把「通信描述」与「执行」绑死在语法里，导致封装、组合、取消与泄漏治理都要靠约定和 goroutine 补丁——CML 用 30 年前的事件模型说明：把通信做成一等值后，选择/超时/取消/后置处理才能统一抽象。

接下来，第一部分，核心概念关系。

关系脉络如下：put-evt，recv-evt，然后choice-evt，然后sync，然后nack，取消

接下来，第二部分，认知纠偏。

认知纠偏

误解：reflect.Select 已让 Go 等价于 CML。它只解决分支数量动态，通信仍无法作为值独立存在、返回、再叠加超时。

接下来，第三部分，反驳。

反驳

对立视角：「Go 够简单，CML 是学术炫技」

简单若意味着无法封装通信与必然 goroutine 补丁，规模上来泄漏和丢消息成本会反超你省下的语法复杂度。

接下来，第四部分，【概念拆解卡】事件 vs Go select。

在讲什么问题，为何不能把「向 ch 发送」封装成函数返回值供上层再选择。

关键理解，channel-put-evt 不发送，sync 才提交；Go 里语句到达即执行。

怎么落地，封装并发 API 时延迟启动——别把 goroutine/请求在构造时就跑起来。

边界说明，不能把整套 CML 运行时搬进 Go；学术模型≠生产迁移。

原文依据，「在 select 里，ch1 <- 5 是动作描述；拿出来就立刻变成执行。」

接下来，第五部分，【方法/工具卡】三大组合子。

handle-evt：提交后的 post-commitment，对应 select 的 case 体，可挂在事件上封装转换。

choice-evt：「二选一」本身也是值，可再与 timeout-evt 组合；sync 前 HTTP 请求未发出。

guard-evt：提交前 setup（如每次新建 resp channel），调用者 API 不变。

对比 Go「起两个 goroutine 抢最快 URL」：goroutine 一启动就在干活，不是延迟选择。

接下来，第六部分，【跨概念对比表】Go vs CML 取消与泄漏。

取消，context 逐层传递约定，nack-guard-evt 内建，Go 顶层传递，CML 事件自决

超时+转换，onePlus+select 易泄漏丢消息，handle-evt 未选中不取消息，Wingo 2016 认错案例

阻塞线程，goroutine 常驻，不可达阻塞线程可被 GC，Go 1.27 goroutineleak 仅诊断

接下来，第七部分，【避坑清单卡】onePlus 超时陷阱。

坑名，select 超时先触发，onePlus 内 goroutine 仍阻塞，数字消失+泄漏。

解法，转换逻辑与超时写在同一 select（关注点混杂），或重新设计延迟执行。

严重程度，数据丢失为致命；泄漏为小心（可用 goroutineleak profile）。

接下来，第八部分，【决策/选型表】Go 工程师怎么用这篇。

库 API 设计，延迟执行+显式 Start，对齐「事件先于 sync」，构造即起 goroutine

线上慢涨内存，Go 1.27 goroutineleak，可达性检测泄漏，以为 profile=自动回收

取消语义，ctx + 明确关闭 done，Go 惯例可落地，指望 nack 语义自动出现

极致组合并发，Racket/专用运行时，CML 完整语义，硬改 Go 语言

接下来，第九部分，【心法/原则卡】描述与执行分离。

原则，通信操作表示为独立于执行的值，选择/取消/前后置才同一抽象。

落地：四条启发——延迟执行、转换与等待分离、每条 goroutine 有退出路径、跑 goroutineleak。

边界：全局变量可达的 channel 泄漏 profile 识别不了。

接下来，第十部分，总结与行动。

结论

Go select 是语法点，CML 事件是值，组合空间更大。

handle/choice/guard 统一超时、取消与后置处理。

Wingo 案例说明封装转换+超时的结构性风险。

Go 1.27 goroutineleak 是诊断，CML 是语义级回收。

借鉴思路即可，不必迁到 Racket。

审查库里「返回 channel 即启动 goroutine」的 API。

用 goroutineleak profile 扫一遍长期运行服务。

读 Nikhil 原文与 Wingo 两篇认错文对照 select 边界。

新并发功能先画「描述，得到执行，得到取消」三阶段再写代码。

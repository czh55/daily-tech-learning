接下来，第二部分，认知纠偏。

认知纠偏

误解：编译通过 + 确定性回放全绿 = 迁移成功。原文强调借用检查器只证明语言规则，不证明架构合理、热路径无多余分配或模块边界清晰。

接下来，第三部分，反驳。

反驳

对立视角：「有 AI 就不用懂 Rust，能编译就行」

借用检查器正是要逼你思考所有权；若用 clone 堆出生成的「合法垃圾」，你得到的是更慢、更难改的遗留系统——而且 AI 一天能造一整年的债。懂 Rust 工程实践不是为了炫技，而是为了把约束写进 Agent，否则它永远选最容易过编译的那条路。

接下来，第四部分，【概念拆解卡】Borrow-checker appeasement debt。

在讲什么问题，AI 用迎合借用检查器的局部技巧消除报错，却牺牲 Rust 倡导的合理所有权与工程设计。

关键理解，不违反 Rust 规则，但偏离「认真划分状态边界」的设计意图；把每次 borrow 报错当成编译题而非架构信号。

和其他概念关系：区别于传统 C++ 内存安全债；更接近「意大利面式语言翻译」——语法换新、结构未重塑。

怎么落地用：审计 AI Rust 时单独建维度表：语法/功能/确定性/架构/性能/可维护性，后三项不能从测试推断。

边界说明，合理场景下 Clone、mem::take 仍合法；债发生在热循环 175 次 clone、巨型单文件等系统性滥用。

原文依据，「AI 没有违反 Rust 的规则……逐渐偏离了 Rust 原本希望开发者采用的工程设计方式。」

接下来，第五部分，【跨概念对比表】质量六维 vs AI 迁移后表现。

语法/类型，通过，必要但不充分

功能/确定性，3091/3091 哈希一致，可保持的同时优化架构

接下来，第六部分，【概念拆解卡】案例中的四类迎合手法。

压扁 OOP：19 类 ，得到 一个 12,349 行 game.rs，消灭多对象可变借用冲突。

热路径 Clone：约 175 次 clone/collect，把借用冲突当局部题。

mem::take 转移：临时掏空字段再塞回，状态机难推理。

渲染管线：每帧 clone 全像素缓冲 + 每帧 4 线程 scope（900 帧约 3840 线程），4 核机上拖垮模拟。

合理替代：GameMap/WorldState/NavState 分治、Arena 索引、可复用环形缓冲——人类重构已验证且测试仍全绿。

原文依据，「900 帧视频累计产生了约 5.9GB 的堆内存分配。」

接下来，第七部分，【方法/工具卡】AGENTS.md 与架构硬约束。

核心思路：AI 缺默认工程品味，须把 Rust 惯用法写进 Agent 可读规则并尽量自动化。

操作步骤，① 在 CLAUDE.md/AGENTS.md 写清 Newtype、少 Arc、Channel 共享、禁热循环无理由堆分配 ，得到 ② Clippy/自定义 Lint + Criterion 基准 ，得到 ③ CI 性能预算与架构规则 ，得到 ④ 独立审查 Agent（新上下文）。

选型条件，大模型迁移、长时 Agent 会话、缺少人类架构 owner 时必做。

避坑，规则只躺在长 Markdown 里不生效；写代码 Agent 自我验收会沿原错误架构继续「优化」。

对比：功能 TDD 验行为；架构约束驱动验结构与性能意图。

接下来，第八部分，【心法/原则卡】从「做什么」到「怎样才算做好」。

原则，迁移指令必须捆绑成功标准：性能不低于原版、热路径分配需论证、模块体量上限、Benchmark 进 CI、重构需独立审查。

为什么：「迁移到 Rust」对 AI 只意味着消错；对人类意味着安全 + 性能 + 可演进。

怎么落地，先让 Agent 输出架构方案并追问冲突，再写码；关键决策人类签收。

边界：小脚本/原型可放宽；确定性模拟、渲染管线、长生命周期系统不可放宽。

原文支撑：社区观点——「不要只告诉 AI 做什么，还要告诉它怎样才算做好。」

接下来，第九部分，【决策/选型表】审查与 Agent 工作流。

大体积 AI 首稿，独立审查 Agent + 人审架构，打破生成者惯性，仅 rerun 测试，掩盖 appeasement 模式

Rust 热循环，Benchmark + 分配审计，借用检查器看不见 clone 成本，见错就 clone，复利性能债

多 Agent 团队，20% 时间维护工作流规则，代码生产机器需运维，只堆模型能力，工作流决定下限

语言迁移，重塑状态边界，避免「意大利面 Rust」，1:1 语法翻译，历史教训在 AI 时代加速重演

接下来，第十一部分，总结与行动。

结论

Reddit 实录：Claude 迁 Rust 测试全绿，却出现巨石文件、175 次热循环 clone、渲染海量分配——借用检查器迎合型技术债。

人类重构：3 crate + 状态重划 + 缓冲复用 ，得到 1.9× 模拟、~3× 渲染，确定性不变。

防范重心从功能测试扩展到目标驱动、架构约束自动化、独立审查。

换语言/换 AI 不自动消灭债；生成加速要求审查与规则同步加速。

为 Rust Agent 项目起草 AGENTS.md：热循环分配、模块边界、Channel vs Arc 优先级。

对 AI 首稿跑 Criterion/分配 profiler，设 CI 回归阈值。

大迁移拆阶段：架构方案评审 ，得到 实现 ，得到 新上下文代码审查。

审计存量 AI Rust：单列「clone/行」与最大文件行数指标。

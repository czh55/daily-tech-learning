一句话概括。本文解决的核心问题是：当 Agent 能自主改码、测、部署时，如何用四道可强制执行的安全边界与三级成熟度模型，把「更聪明的模型」升级为可审计、可渐进建设的软件工厂，而不是扩大权限的超级脚本。

接下来，第一部分，核心概念关系。

关系脉络如下：Sandbox，然后Network，然后Supply Chain，然后Identity

接下来，第二部分，认知纠偏。

认知纠偏

误解：软件工厂=更强的 Coding Agent。白皮书强调它是接收任务，得到生产，得到验证，得到反馈的系统；Vercel/Uber 等案例数字是引用数据，不能当作每家企业的默认产能。

接下来，第三部分，反驳。

反驳

对立视角：「现有 IAM + K8s NetworkPolicy 已经够用，不必新造软件工厂概念」

传统 IAM 约束的是预编程序；Agent 在运行时发明路径，需要任务级沙箱、动态供应链与按次授权——白皮书是把已有控件重排成 Agent 时代的生产流水线，不是否定 K8s。

接下来，第四部分，【概念拆解卡】决策与授权分离。

在讲什么问题，Agent 能「决定」做什么，为何不能同时「有权」做什么？

关键理解，提示词里的「只用测试环境」在能读到生产 Token 时只是建议；PocketOS 九秒删库说明权限必须外部强制执行。

典型场景，告警，得到隔离沙箱分析，得到改码测，得到PR，得到策略审批，得到部署，得到观测回滚。

边界说明，适用于 Agent 可触达内网/云 API 的企业；纯本地 Copilot 仍需部分原则但强度不同。

原文依据，「Agent 负责提出行动方案，策略系统负责授权，外部基础设施负责强制执行。」

接下来，第五部分，【方法/工具卡】四道边界落地要点。

Sandbox：每任务独立可销毁环境；禁 docker.sock；非特权；仅挂载所需仓库——「进容器」≠安全。

Network：沙箱外出口代理、默认拒绝；细到「支付服务过去一小时日志」而非全网通。

Supply Chain：批准镜像/Harness/Skill；制品库+完整性；Agent 不能绕过镜像直拉公网。

Identity：每 Agent 独立身份、短生命周期凭据；操作关联任务与请求者。

怎么落地，从最小闭环（单仓库 PR Agent + 沙箱 + 审计）扩展，而非一次买齐四产品。

接下来，第六部分，【跨概念对比表】三道边界常见误配。

隔离，Agent 跑在 Docker，不可改隔离、无 sock、任务级销毁，容器≠沙箱

网络，设 HTTP_PROXY 环境变量，沙箱外强制 egress 策略，Agent 可绕过 env

依赖，口头要求用内网镜像，物理上无法直连公网源，策略要可执行

接下来，第七部分，【决策/选型表】三级成熟度怎么选。

首次试点 Agent 改 PR，Level 1 人工编排，人批准每步，风险可控，直接 Level 3，无审计与边界会复现 PocketOS 类事件

固定工单流水线，Level 2 工作流编排，步骤可重复、策略嵌入，完全自由 Agent，路径不可预测

边界+观测已成熟，Level 3 Agent 编排，自主领任务但在策略内，跳过 L1/L2，缺证据链与回滚习惯

接下来，第八部分，【心法/原则卡】凭据不交给 Agent。

原则，Agent 提请求，授权服务判定，代理代为访问——模型不持有长期超级 Token。

为什么重要，恶意提示词或错误推理在凭据在手时等于即时越权。

怎么落地，Go 栈用受控入口启动 Agent；代码里用策略引擎表达「能否 merge/deploy」。

适用边界，仍需人工 break-glass 与合规保留策略例外流程。

接下来，第九部分，【避坑清单卡】软件工厂建设陷阱。

坑名，把网络可达性当成应用层授权。

原因，Tailscale 等只解决「能否连上」，不替代 API scope。

解法，网络策略 + OAuth scope + 审计三元同时设计。

严重程度，致命——误配等于给 Agent 内网地图。

接下来，第十部分，总结与行动。

结论

下一站是软件工厂系统，不是单点更聪明模型。

四边界（沙箱/网络/供应链/身份）必须可强制执行，不能靠提示词。

执行编排入口 + 全链路可观测构成安全闭环证据。

三级成熟度支持从人工编排渐进到 Agent 编排。

Go 团队可从最小 PR 闭环起步，用代码表达权限边界。

阅读 Agent Baseline《The Secure Software Factory》1.0 草案原文。

绘制本组织 Agent 当前能触达的凭据与网络路径（红队视角）。

为一次 Agent 任务定义独立沙箱 profile（无 docker.sock）。

建立「每次运行必留审计」的最小字段集（谁、何任务、何操作）。

选 Level 1 试点：告警，得到沙箱分析，得到PR，人工批准 merge。

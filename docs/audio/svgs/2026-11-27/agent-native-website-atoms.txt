欢迎收听每日技术学习语音讲解。本期主题，Atoms 实战：一人搭建 Agent 原生网站「门道」。标签包括Atoms 无代码、多 Agent 编辑部、会员 / Stripe。本次讲解预计时长 约 10 到 11 分钟，共 12 个部分。好，我们开始。

一句话概括。本文解决的核心问题是：个人如何在不写代码的前提下，用 Atoms 把 Agent 装进网站当「员工」——以门道 mendao.pub.atoms.world 为例，用深度研究定卖什么、竞赛模式定架构、双编辑 Agent 每日收稿，Stripe 十九元月费，两人订阅即可覆盖模型成本。

接下来，第一部分，核心概念关系。

关系脉络如下：深度研究定方向，然后竞赛模式定架构，然后编辑部 Agent，然后定时任务，然后Stripe 会员，然后SEO + Agent 入口

接下来，第二部分，认知纠偏。

认知纠偏

误解：Agent 原生网站 = 只给来访 Agent 看 robots/skill。门道一半在站内 Agent 当编辑决策，一半在读者 Agent 带 Skill 来查，两端都是 Agent。

接下来，第三部分，反驳。

反驳

对立视角：资深内容创业者——「AI 收稿就是洗稿聚合，订阅站活不过半年。」

门道价值在双编辑+闸门引文校验与「只链不全文」的减量索引，若你不维护领域卡片与下架表，才会退化成低质 RSS 农场。

接下来，第四部分，【概念拆解卡】Agent 原生网站 vs 传统内容站。

在讲什么：决策与日常运营由站内 Agent 完成（收稿、写理由、更新），而不只是 CMS + 人工编辑。

关键理解，卖的是持续更新的「最佳实践索引」，读者为省上下文窗口与时间订阅。

关系：领域 ，得到 步骤 ，得到 问题 ，得到 做法 四层模型；免费前 10 篇，第 11 篇起锁会员。

落地：先选垂直人群 + 三个「天天会搜」的实操问题，再搭站。

边界：不转载全文，只中文标题+编者按+入选理由+原文链；下架只打标记。

原文：「门道卖的是信息减量……最佳实践每天都在变，读者就有理由一直订阅下去。」

接下来，第五部分，【方法/工具卡】第 0–2 步：深度研究与竞赛模式。

深度研究（Iris）：先要大纲确认方向；十个问题用读者会搜的原句；每题 ≥3 个一手做法+来源编号；同类站价格表禁瞎估。

竞赛模式：同一段架构提示词出四版，选「读者一进来知道先看哪儿」的刊物型，而非术语落地页。

架构要点：读者 Vite+React；编辑部 Vercel AI SDK Python；后台 FastAPI+Postgres 全在 Atoms 云。

避坑，研究报告是起点不是站内容；挑三个天天碰的问题填进架构提示词。

验收：四版首页能点领域，得到步骤，得到问题；问题页无文章时显示「编辑部还没有收录文章」。

接下来，第六部分，【方法/工具卡】编辑部五日流水线。

步骤：收集 RSS（首源 90 天/其后 7 天），得到 程序筛选（重复/广告词/太短等），得到 责任编辑 JSON 判决 ，得到 复核编辑盲审拿不准/疑点 ，得到 程序闸门发布。

岗位：责任编辑全工具；复核编辑仅 read+decide，看不到编辑结论。

记忆：交接日志 + 核心记忆 ≤1000 字，禁 URL/抄原文。

可靠性：daily-日期幂等；8 分钟一批；模型连错 3 次停步；作业队列 md_jobs 续跑。

原文：「复核编辑每次新开一个对话，看不到责任编辑的结论。」

接下来，第七部分，【决策/选型表】免费 vs 会员与鉴权。

每问题前 10 篇，永久免费全文链，SEO+试用，前端各自判断权限

第 11 篇起，仅标题+锁+去 /membership，转化，多处重复写死逻辑

读权限，后端单函数 canReadFull，一致，站长默认看全站

外站 Agent，Bearer md_ 密钥，5000 次/日，密钥写进日志

定时编辑部，x-run-secret 内部头，防误触，未配密钥仍开放 internal

接下来，第八部分，【跨概念对比表】信息增量 vs 信息减量。

价值，更多新资讯，已筛的实操做法，订阅动机不同

生产，人工或简单聚合，Agent 编辑+双审，边际成本在模型

读者 Agent，仍要读大量文，Skill+API/.md，省上下文

变现，广告/流量，月会员 19 元，2 人即可回本量级

接下来，第九部分，【避坑清单卡】提示词与数据工程陷阱。

研究方向错：问题写成「内容策略优化」而非「选题怎么找」。解：大纲必人工过一遍。

示例文章占位：架构要求真文前进场显示空状态。严重度：中（SEO 与信任）。

权限散落：免费界线只许后端一函数。解：接口验收 visible vs total。

复核可见编辑结论：破坏双盲。解：新对话+仅领域卡片+原文。

核心记忆灌水：超 1000 字或含链拒写。解：迁移行业时整张换领域卡片。

接下来，第十部分，【心法/原则卡】一人副业的产品纪律。

原则，一段提示词只做一件事，等 Alex 验收后再发下一段——顺序表 0–12 不可跳步。

成本：模型月耗约三十元内，两会员覆盖——先验证订阅再扩领域。

迁移：换行业改人群、站名、领域、三问题；编辑部与 Stripe 骨架复用。

边界：Atoms 黑盒云；深度定制与合规需自评平台连接器能力。

接下来，第十一部分，总结与行动。

结论

Agent 原生站 = 站内 Agent 决策 + 站外 Agent 消费，门道用编辑部自动化每日更新。

深度研究定三个高频问题 ，得到 竞赛模式定刊物型 UX ，得到 md_ 全套表与单点鉴权。

收集/筛选/判断/审核/发布五步；复核盲审+程序闸门保质量。

前 10 免费 + Stripe 会员 + Agent API 密钥，成本门槛低。

提示词按序交付、逐项验收是可复制的一人副业方法论。

用深度研究模板跑一遍你的垂直人群，挑出三个天天搜的问题。

竞赛模式发架构提示词，选「刊物型」方案并建 md_ 表+接口。

配 RSS、双编辑手册、领域卡片，设 daily 定时与 EDITORIAL_RUN_SECRET。

Stripe 测试模式接通会员，核对 visible/total 与 sitemap 仅免费页。

给读者 Agent 写 Skill + /agent Markdown 与 .md 路由。
